🚀 GUIDE DÉMARRAGE RAPIDE - Portfolio HERON Loan

═══════════════════════════════════════════════════════════════

📦 INSTALLATION

1. Ouvrir PowerShell dans le dossier portfolio:
   cd "c:\Users\Loan\Desktop\Pro\portfolio"

2. Installer les dépendances:
   npm install

3. Lancer le serveur:
   npm start

4. Ouvrir le navigateur:
   http://localhost:3000

═══════════════════════════════════════════════════════════════

📂 STRUCTURE DU PROJET

backend/
  ├── server.js              → Serveur Express principal
  ├── routes/
  │   ├── portfolio.js       → API données portfolio
  │   └── contact.js         → API formulaire contact
  └── controllers/
      └── portfolioController.js → Données du portfolio

public/
  ├── pages/                 → Pages HTML (6 fichiers)
  ├── assets/
  │   ├── css/              → Styles (8 fichiers)
  │   ├── js/               → Scripts (7 fichiers)
  │   └── images/           → Images & assets

═══════════════════════════════════════════════════════════════

🔄 WORKFLOW

1. Modifier les données:
   → backend/controllers/portfolioController.js

2. Ajouter/modifier une page:
   → public/pages/*.html
   → public/assets/css/*.css
   → public/assets/js/*.js

3. Le backend sert automatiquement les pages

═══════════════════════════════════════════════════════════════

🌐 PAGES CRÉÉES

═══════════════════════════════════════════════════════════════

🔌 API ROUTES

GET  /api/portfolio              → Toutes les données
GET  /api/portfolio/person       → Infos personnelles
GET  /api/portfolio/skills       → Compétences
GET  /api/portfolio/projects     → Tous les projets
GET  /api/portfolio/experience   → Expérience
POST /api/contact                → Envoyer un message
